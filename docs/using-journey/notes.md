# Notes and where they go

You can write a note from a client's profile (the **Note** button), from **Notes** in a session, on a machine's card, on the briefing, at Finish and on the Wrap-up. Nothing is required to save.

**Every note gets two choices.**

**What it's for**, so it can be found and acted on later: Coaching & equipment, Health, Incident, Retention, FORD / Life, or Preference. Your studio's leaders also see Health, Incident and Retention notes.

**Where it goes:**

- **Profile only**: kept on the client's profile, found under what it's for.
- **Next time**: read out on the briefing at the client's next four sessions, whoever trains them. Adding to it starts the four again.
- **Critical**: on every briefing until someone closes it, and a red triangle on the client's Hub card for everyone.
- **Just for me**: your own notebook. It never goes on the client's record.

**A note is a conversation.** When something changes, add to the note that's already there instead of starting a new one. If the news is different, adding to it keeps the history: it never wipes the first note. Anyone can close a note or open it again.

**Seen it enough?** "No need to remind me" stops a note showing for you. It still shows for everyone else, and any new update brings it back.

A note written during a session is linked to that session, so you can see when and why it was written.
