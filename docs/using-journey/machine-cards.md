# The machine cards

A machine has two cards: one for **a client on that machine**, and one for **the studio's machine itself**.

## A client on a machine

Open it by tapping a machine's name in a session or on the profile, or with **Set up** on the Now Bar.

- At the top: last time, and the machine's safety notes.
- **The settings.** Tap a setting, type it, and tap **Save**. Save closes the card, and Undo is there if you need it. **Use studio standard** fills in the studio's usual setting. If you want to say why you changed a setting, **Why?** is there. It's never required.
- **Notes** for this client on this machine. In a session they're right under the settings; on the profile they come after the chart.
- **The chart** shows how the client has done here. The green percentage counts from the starting weight on file.
- **Setting changes** lists when each setting changed.

The card never suggests a next weight.

## The studio's machine

Open it from My Studio, then Machines (the studio's map), or from Relay or the Catalog. It has four parts: **Learn**, **Clean**, **Maintain** and **Set up**.

- **Clean** shows how many days since it was wiped and deep cleaned.
- **Maintain** has **Report a problem**, which tells your studio's leaders.
- Only a leader marks a machine out of service.
